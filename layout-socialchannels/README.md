# Opportunity — Social Channels & Sync Tracker

Interactive prototype for the Opportunity page layout, adding a **Social Channels** quick link that lets Account Managers manage YouTube allow-listing without leaving Salesforce.

## What it covers
- Flyout listing all channels/videos tied to the Opportunity: type, channel/video ID, status, coverage dates, licence codes
- Per-row actions: remove, retry failed items
- Inline "Add" row for new URLs, bulk submit via **Create/Update Allow Listing**
- Status badges: Draft, Processing, Active, Needs attention, Expired — plus a grace-period indicator for coverage expiry
- **Video Claim Clearance** flow: paste URL → extract video ID → check claim status → submit clearance or escalate to ops

## Status
Click-through prototype, not connected to live Sync Tracker or Salesforce data.
